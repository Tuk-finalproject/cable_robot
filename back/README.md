# back — 현장 백엔드

로봇 CM5에서 실행할 현장 API의 개발 공간입니다. 현재 실행 코드는 없으며 아래는 구현 계획입니다.

## 담당 범위

- FastAPI로 지도·로봇 상태 제공, WebSocket으로 진행 상태 전달
- 사용자가 그린 경로를 ROS 2 로컬 계획기에 전달하고 보정 결과 반환
- 지도 버전과 승인 해시를 확인한 뒤 작업·경로를 SQLite에 저장
- 웹 재접속 시 현재 상태·승인 저장 결과 조회
- 인터넷 연결 후 server의 클라우드 API로 이력·지도 동기화
- front의 완성된 정적 빌드를 CM5에서 제공해 로봇 Wi-Fi만으로 접속 지원

## 로봇 연동 원칙

ROS 2는 지도 생성·위치 추정·경로 계산을 맡고, ESP32는 모터·스풀 제어를 맡습니다. 웹 요청을 모터 명령으로 직접 전달하지 않습니다. 장력 초과·위치 상실·명령 만료에 대한 감속 또는 정지는 로봇 내부에서 처리하도록 설계합니다.

SQLite와 지도 파일은 런타임 데이터 경로에 저장하고 Git에서 제외합니다. 실제 API 스키마와 실행 명령은 첫 통합 시연 때 코드와 함께 추가합니다.
